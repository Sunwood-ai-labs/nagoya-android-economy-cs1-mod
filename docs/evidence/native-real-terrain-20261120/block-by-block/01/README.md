# 01 桜通口ロータリー・タワーズ前

## 整備前の照合

航空写真ではタワーズ前の歩行者空間に舗装の帯が通り、名駅通側に横断帯がある。基準画面では路面と広場の境が目立ち、横断位置を読みにくい。 [国土地理院の航空写真](https://maps.gsi.go.jp/#18/35.17088/136.88156/&base=seamlessphoto&ls=seamlessphoto&disp=1)

## 実機で反映した内容

地図に記録された横断点に白線を描き、駅前広場に歩行者の舗装帯を足す。ロータリーと庭園は残す。

同じ座標・ズーム・方位・角度で前後を撮影した。起動中のゲームが区画01のメッシュ1個、三角形81件を受け付けた。

## 前後の画面で確認したこと

車道の上端と広場脇に白い横断帯が見える。舗装帯はタワーズ沿いに続き、ロータリー中央と庭園の植栽は残った。
