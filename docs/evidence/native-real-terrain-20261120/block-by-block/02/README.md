# 02 大名古屋ビルヂング・桜通東側

## 整備前の照合

桜通の交差点と学校の手前に横断歩道が見える。基準画面では車道が一色で、歩道からどこを渡るか分かりにくい。 [国土地理院の航空写真](https://maps.gsi.go.jp/#18/35.17088/136.88156/&base=seamlessphoto&ls=seamlessphoto&disp=1)

## 実機で反映した内容

大名古屋ビルヂング東側から桜通東行きの区画に、横断歩道と停止位置が読める白線を追加する。

同じ座標・ズーム・方位・角度で前後を撮影した。起動中のゲームが区画02のメッシュ1個、三角形85件を受け付けた。
