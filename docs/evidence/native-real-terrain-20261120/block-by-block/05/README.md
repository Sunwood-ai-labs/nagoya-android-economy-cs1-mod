# 05 JPタワー・牛島町の駅北街区

## 整備前の照合

駅北側の航空写真ではJPタワー屋上に設備区画と着陸帯の模様が読める。基準画面では高層部屋根が明るい無地。 [国土地理院の航空写真](https://maps.gsi.go.jp/#18/35.17088/136.88156/&base=seamlessphoto&ls=seamlessphoto&disp=1)

## 実機で反映した内容

既存の屋根の高さをモデルから読み、屋上の区画、着陸帯の模様、小さな設備を配置する。

同じ座標・ズーム・方位・角度で前後を撮影した。起動中のゲームが区画05のメッシュ1個、三角形57件を受け付けた。

## 前後の画面で確認したこと

JPタワーの無地の屋根に緑色の着陸帯と白線が見える。真上の画像では着陸帯の南端が画面下端にかかる。
