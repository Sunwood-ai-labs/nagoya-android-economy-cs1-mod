# 06 名古屋駅北の線路脇・椿町北端

## 整備前の照合

写真では北側の並行線路の間に砂利と作業通路が続く。基準画面には線路の中央に長い芝の筋が見える。 [国土地理院の航空写真](https://maps.gsi.go.jp/#18/35.17088/136.88156/&base=seamlessphoto&ls=seamlessphoto&disp=1)

## 実機で反映した内容

並行線路の間の帯だけを暗い砂利面とし、点検用の細い帯を追加する。建物側の敷地には広げない。

同じ座標・ズーム・方位・角度で前後を撮影した。起動中のゲームが区画06のメッシュ1個、三角形93件を受け付けた。

並行線路の中央にあった芝の筋の一部が暗色の地面に変わった。北端には細い芝の帯が残る。
