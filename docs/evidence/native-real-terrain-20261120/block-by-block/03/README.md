# 03 太閤通口バスのりば・駅前広場

## 整備前の照合

航空写真では線路脇のバス接車帯と乗車側の島が分かれる。基準画面でループは見えるが、待合側の境界が判別しにくい。 [国土地理院の航空写真](https://maps.gsi.go.jp/#18/35.17088/136.88156/&base=seamlessphoto&ls=seamlessphoto&disp=1)

## 実機で反映した内容

地図上のバス停に隣接し、車道を避けた位置に待合の上屋を置き、乗車側の舗装端を明示する。

同じ座標・ズーム・方位・角度で前後を撮影した。起動中のゲームが区画03のメッシュ1個、三角形71件を受け付けた。
