# 08 広小路通・線路の南側アプローチ

## 整備前の照合

広小路通側の航空写真では跨道部の両側に線路敷が連続する。基準画面では南の線路脇に芝色が現れ、線路敷の色の切り替わりも大きい。 [国土地理院の航空写真](https://maps.gsi.go.jp/#18/35.17088/136.88156/&base=seamlessphoto&ls=seamlessphoto&disp=1)

## 実機で反映した内容

線路に近い細い縁と保守通路を補う。既存の車道路面には重ねない。

同じ座標・ズーム・方位・角度で前後を撮影した。起動中のゲームが区画08のメッシュ1個、三角形97件を受け付けた。

## 前後の画面で確認したこと

南側の線路脇に細い暗色の帯が見える。駅構内と南側アプローチの線路敷で素材の境目はまだ読める。
