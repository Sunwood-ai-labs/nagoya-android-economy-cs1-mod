# 04 椿町・駅西銀座の街区

## 整備前の照合

航空写真にある生活道路は既に入っている。街路に接する平面駐車場が基準画面では一様な砂色に見える。 [国土地理院の航空写真](https://maps.gsi.go.jp/#18/35.17088/136.88156/&base=seamlessphoto&ls=seamlessphoto&disp=1)

## 実機で反映した内容

OSMの平面駐車場にアスファルトと枠線を描き、工事区画と見分けられるようにする。

同じ座標・ズーム・方位・角度で前後を撮影した。起動中のゲームが区画04のメッシュ1個、三角形822件を受け付けた。
