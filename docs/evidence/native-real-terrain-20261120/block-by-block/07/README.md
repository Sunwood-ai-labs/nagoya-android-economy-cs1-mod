# 07 名鉄百貨店本館・名駅通南側

## 整備前の照合

名鉄百貨店本館の屋根に設備と段差が見え、名駅通に横断歩道がある。基準画面は一枚の明るい屋根で交差部に白線がない。 [国土地理院の航空写真](https://maps.gsi.go.jp/#18/35.17088/136.88156/&base=seamlessphoto&ls=seamlessphoto&disp=1)

## 実機で反映した内容

本館の屋根に低い設備帯と段差、名駅通に横断帯を追加する。周辺の接道は現行のままにする。

同じ座標・ズーム・方位・角度で前後を撮影した。起動中のゲームが区画07のメッシュ1個、三角形56件を受け付けた。
