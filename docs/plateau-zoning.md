# PLATEAU建物に住宅区画を割り当てる

駅周辺で、道路沿いのPLATEAU建物6棟を対象に、既存のCS1道路に属する区画セルを検査した。個別のPLATEAUメッシュが表示され、空いている有効なCS1区画セルが建物の範囲に収まり、ネイティブの建設判定を通る場合に、対応するCS1建物を作成する。

作成したCS1建物の区画・住居や職場のユニットは、CS1が管理する。対応するPLATEAUメッシュが表示されている間、そのCS1建物の標準形状のみ非表示にする。バインドは建物IDと作成時の世代を照合する。

## 実機での確認

| 項目 | 結果 |
| --- | --- |
| PLATEAU建物 | `bldg_60f41894-285c-44dd-a6db-f20236f52bc6` |
| 対応するCS1建物 | ID `13921`、`ResidentialLow` |
| 実際に割り当たった区画 | 1セル |
| CS1の住宅ユニット | 1 |
| 実際に入居した住民 | 2人を観測 |
| 商業の候補・密度別の他候補 | 区画の条件に適合せず適用なし |

[実ゲームの区画・建物・入居の読み戻し](evidence/plateau-zoning-20261119.json)

同じマップの導入試験では、設定32体に対して、実際の空き住宅に6体が入居した。6体とも標準の職場ユニットに所属した時点を [就業の観測記録](evidence/android-life-zoned-20261119.json) に保存している。今回区画を割り当てた建物の入居者は、このアンドロイド6体と区別して集計した。

この地区のCS1標準の住居・職場で行った別の生活試験は [アンドロイドの生活と雇用](android-life.md) を参照。PLATEAUの商業建物での就業と市域全体への割り当ては未確認。住宅とゾーンはCS1セーブに保存できるが、再読込後のメッシュとCS1建物IDのひも付けはまだ自動復元しない。

駅周辺の適用には `tools/apply_plateau_zoning.ps1` を使う。開始セーブ、表示中のメッシュ、実道路を照合した後、そのゲーム実行にだけ有効な指示を書き込む。
